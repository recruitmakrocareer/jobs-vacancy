# Makro Talent Profile

หน้าเว็บสำหรับทีมสรรหาบุคลากร ใช้เปลี่ยนข้อมูลใบสมัครจาก Google Sheets ให้เป็นโปรไฟล์ Resume ที่อ่านง่าย ค้นหาและกรองตามสาขา/ตำแหน่งได้ พร้อมมุมมองสำหรับพิมพ์หรือบันทึกเป็น PDF

## ใช้งานในเครื่อง

```bash
python3 -m http.server 4173
```

จากนั้นเปิด `http://localhost:4173`

ระบบจะพยายามอ่านข้อมูลจาก Google Sheets ที่เผยแพร่ไว้ หากเครือข่ายไม่อนุญาต สามารถกด **นำเข้าข้อมูล** แล้ววางข้อมูลที่คัดลอกจาก Google Sheets พร้อมแถวหัวตารางได้โดยตรง
